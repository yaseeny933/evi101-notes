# EVI101 — Evidence · Study Notes

Self-contained HTML study guides for **EDU EVI101: Evidence** (Harvard GSE), a research-methods course taught in a Team-Based-Learning format. One guide per session (per *type of evidence*), each with core concepts, a diagram, a quiz-yourself glossary, and iRAT-prep practice.

Open `index.html` for the dashboard. Live via GitHub Pages once enabled (Settings → Pages → Deploy from branch `main` / root).

Personal study notes paraphrasing course material for review.
